    快捷预设
    

    








    

    快捷预设只用于快速填充接口和模型；下面的已保存预设会连同 API Key、温度一起切换。
    

    

    

    
已保存预设





    

    

    还没有保存的预设。填写下面的接口信息后，点击“＋新建预设”。选择已有预设后可编辑下面的接口信息，再点击“更新当前”覆盖该预设。
    

    

    

    Base URL
    

    


    

    填写中转站的接口地址。若以 /v1 结尾会自动补 /chat/completions，其他情况补 /v1/chat/completions。
    

    

    

    API Key
    

    



    

    仅保存在本机 IndexedDB，不会上传到任何服务器。
    

    

    

    
模型


    

    


    

    如 gpt-4o-mini、deepseek-chat、moonshot-v1-8k、glm-4-flash 等。点右上角可直接拉取该站支持的模型列表。
    

    

    

    温度
    

    

0.85

    

    越高越有创造力，越低越稳定。角色扮演建议 0.8 ~ 1.1。
    

    

    

    最大回复长度（tokens）
    

    


    

    留空或 0 表示不传该字段，由服务端决定。
    

    

    



    

    

    

    

    

    


    语音转文字
    

    

    

    

    

    

    快捷预设
    

    



    

    这里独立配置“语音 → 文字”的识别服务，不使用聊天 AI 接口。默认按 OpenAI-compatible 的音频转写协议调用。
    

    

    

    Base URL
    

    


    

    填写 API 根地址。若以 /v1 结尾，会自动请求 /audio/transcriptions。
    

    

    

    API Key
    

    



    

    仅保存在本机 IndexedDB；真正识别时音频会直接从当前设备请求到这里。
    

    

    

    
识别模型


    

    


    

    推荐选择服务端明确标注为 Speech-to-Text / Transcribe 的模型。模型列表不会自动筛选，以兼容不同中转站。
    

    

    

    语言
    

    


    

    有明确语言时建议指定 ISO-639-1 代码，通常能减少识别延迟并提高准确度。
    

    

    

    提示词（可选）
    

    


    

    可放人名、术语、品牌名等，帮助模型理解上下文；不填写时不会上传 prompt 字段。
    

    

    



    

    

    识别请求使用 multipart/form-data 上传当前录音。浏览器 / APK WebView 必须允许麦克风，并且你的 STT 服务需要允许当前页面的跨域请求（CORS）。
    

    

    

    

    


    副API
    

    

    

    

    

    

    快捷预设
    

    








    

    副API独立保存，与主API互不影响；已保存预设会连同 API Key、温度一起切换。
    

    

    

    
已保存预设





    

    

    还没有保存的预设。填写下面的接口信息后，点击“＋新建预设”。选择已有预设后可编辑下面的接口信息，再点击“更新当前”覆盖该副API预设。
    

    

    

    Base URL
    

    


    

    填写中转站的接口地址。若以 /v1 结尾会自动补 /chat/completions，其他情况补 /v1/chat/completions。
    

    

    

    API Key
    

    



    

    仅保存在本机 IndexedDB，不会上传到任何服务器。
    

    

    

    
模型


    

    


    

    如 gpt-4o-mini、deepseek-chat、moonshot-v1-8k、glm-4-flash 等。点右上角可直接拉取该站支持的模型列表。
    

    

    

    温度
    

    

0.85

    

    越高越有创造力，越低越稳定。角色扮演建议 0.8 ~ 1.1。
    

    

    

    最大回复长度（tokens）
    

    


    

    留空或 0 表示不传该字段，由服务端决定。
    

    

    



    

    

    

    

    

    向量记忆 API
    

    

    接口地址
    可填写完整 /embeddings 地址；若填写到 /v1，系统会自动补 /embeddings。
    

    API Key
    

    Embedding 模型
    支持返回 OpenAI 风格 /models 列表的服务；模型列表不会强制筛选，可兼容中转站和自建接口。
    

    召回参数
    先从向量库取候选，再可调用重排 API；候选数量应大于等于最终条数。
    

    

    

    

    

    

    重排 API
    

    

    接口地址
    支持常见 rerank 接口：POST {model, query, documents, top_n}，兼容 /rerank 结尾地址。
    

    API Key
    

    重排模型
    支持返回 OpenAI 风格 /models 列表的服务；模型列表不会强制筛选，便于兼容不同 Rerank 服务。
    

    聊天时会把向量召回的候选记忆交给该接口重新排序；未配置重排 API 时，系统自动使用向量相似度排序，不影响基本功能。
